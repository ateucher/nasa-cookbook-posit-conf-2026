# The NASA Earthdata Cloud Cookbook: A Quarto Collaboration Story

Slides for a talk at posit::conf(2026) about the [NASA Earthdata Cloud Cookbook](https://nasa-openscapes.github.io/earthdata-cloud-cookbook).

The slides are published here: <https://andyteucher.ca/nasa-cookbook-posit-conf-2026/>

### Abstract

A shared problem can help unite people to work together for a common solution, which they can then adapt to address further needs.
NASA Earthdata staff manage over 100 petabytes of data and create tutorials to help scientists access these data with code.
Since 2021, Quarto has helped NASA Openscapes mentors solve a shared problem by being a place to unite and build tutorials together, creating a “Cookbook” of Python and R tutorials with less redundancy – and help establish open source practices across a government agency.
We'll share how over 5 years of Cookbook collaboration and governance have shaped these mentors' workflows, letting them focus on what matters: helping scientists work with NASA Earthdata efficiently.
